# Changelog

## 0.1.0 – first version
- Independent `se.yrell.search` OSGi plugin with dockable search view.
- Manual background indexing of saved Active Links, Filters, Escalations and guides.
- Search modes for text, events, actions, fields, forms and references.
- Exact/possible/text match classes; action path / If vs Else and detail text.
- Multi-select matches and deduplicated objects, BMC native Open and DEF Export.
- Scoped in-memory index with connection/account/overlay checks; no disk cache.
- Controlled cancellation, partial-index warning, name prefilter, max 3000 UI rows.
- Separate Git-friendly build/update scripts; Java 17 tests.
